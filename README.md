# Rebuild of Evangelion Scripts Collection

This folder contains dialog scripts/transcripts for the Rebuild of Evangelion movie series in both English and Japanese.

## Downloaded Files - English Scripts

✅ **Evangelion_1.11_Script.txt** - Evangelion 1.11: You Are (Not) Alone (2007)
✅ **Evangelion_2.22_Script.txt** - Evangelion 2.22: You Can (Not) Advance (2009)
✅ **Evangelion_3.33_Script.txt** - Evangelion 3.33: You Can (Not) Redo (2012)

## Downloaded Files - Japanese Scripts

✅ **Evangelion_3.33_Script_Japanese.txt** - Evangelion 3.33 Japanese dialog (ヱヴァンゲリヲン新劇場版：Q)

## Manual Download Required

❌ **Evangelion 3.0+1.0: Thrice Upon a Time (2021)** - English
- The transcript for the fourth movie is available at Forever Dreaming but requires manual browser access
- URL: https://transcripts.foreverdreaming.org/viewtopic.php?t=145394
- The site blocks automated downloads (returns 403 error)
- Please visit the URL in your browser to view or copy the transcript

## Japanese Scripts Availability

**Limited Availability:** Only Evangelion 3.33 has a publicly available Japanese script on GitHub.
- Movies 1.11, 2.22, and 3.0+1.0 do not have publicly available Japanese scripts
- See `Evangelion_Scripts_URLs_Japanese.md` for alternative sources like:
  - Kitsunekko.net (Japanese subtitle database)
  - OpenSubtitles.org
  - Official Blu-ray subtitle extraction

## All URLs

- `Evangelion_Scripts_URLs.md` - Complete list of English script URLs and sources
- `Evangelion_Scripts_URLs_Japanese.md` - Japanese script sources and alternatives

## Notes

- These are fan-created transcripts from the Evangelion fan community
- English scripts include dialog, scene descriptions, and character interactions
- The 3.33 scripts include timecodes in HH:MM:SS format
- These are not official releases from Studio Khara
